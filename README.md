# gth-data

Go Trainer Helper 앱이 읽는 공개 데이터(일정·레이드·상점 등)입니다.
앱은 `remote/manifest.json`의 버전과 sha256을 확인해 바뀐 파일만 받아 갑니다.

직접 고치지 말고, 비공개 저장소에서 `python3 tools/build_schedule.py` → `python3 tools/publish_remote.py`로 올립니다.

비공식 팬 도구이며 Niantic, Scopely, Nintendo, Creatures, GAME FREAK, The Pokémon Company와 관련이 없습니다.
